# UniServe - University Services Management System

## About the Project

UniServe is a University Services Management System that aims to make it easier for students to access and request different university services through one platform.

Instead of going to different departments to submit requests or report problems, students can use the system to submit their requests online and follow up on their status.

## Main Services

The system provides four main categories of services:

### 1. Student Affairs Services

Students can submit requests related to their university records and personal information, such as:

- Enrollment Certificate Request
- Academic Transcript Request
- Lost Student ID Card Replacement
- Student Information Update

### 2. Technical Support Services

Students can report technical problems or request assistance, including:

- Computer Lab Problems
- Internet Connection Issues
- University Account Problems
- General Technical Support

### 3. Maintenance Services

Students can report problems related to university facilities, such as:

- Classroom Problems
- Lighting Issues
- Air Conditioning Problems
- Other Maintenance Issues

### 4. Complaints and Suggestions

Students can submit complaints, report general problems, or suggest improvements to university services and facilities.

## Main Pages

The system includes the following pages:

- **Login Page:** Allows students to log in to their accounts.
- **Home Page:** Displays the available services and an overview of the student's recent requests and their statuses.
- **Services Page:** Displays the available service categories and allows students to choose the service they need.
- **Create Request Page:** Allows students to fill in the required information and submit a new service request.
- **My Requests Page:** Displays all requests submitted by the student and their current statuses.

## Main Goal

The main goal of UniServe is to organize university services, make submitting requests easier for students, and provide a simple way to follow up on requests without unnecessary visits to university departments.
